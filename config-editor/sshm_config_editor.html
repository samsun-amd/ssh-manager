SSHM Config Editor

離線編輯 · 批次分組 · JSON 原始內容同步預覽

輸出時請選擇上層資料夾，JSON 會儲存至其中的 sshm_config/。

可拖曳 JSON、folder、ZIP、TAR、TAR.GZ／TGZ。每批最多 256 configs、32 MiB（含解壓後）；GUI 寫入需使用 Windows Chrome／Edge。資料僅保留在本頁記憶體。

從 default 開始新增，或拖曳既有設定檔。
